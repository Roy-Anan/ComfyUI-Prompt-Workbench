# ComfyUI Prompt Workbench

一个面向 Windows 的本地 ComfyUI Prompt 创作与管理工作台。它使用本地 LLM
辅助编写、优化和管理图像生成提示词，并通过严格的白名单机制，把审核后的正向/负向
Prompt 写入 ComfyUI 工作流。

> **当前状态：工作流解析与白名单保护、规则库与参数比对、本地 LLM 候选审核、任务队列与
> 生成历史、多命名草稿（收藏/置顶/标签/回收站/跨流复制/环境快照/双向索引）、历史缩略图、
> LoRA 元数据只读骨架、深浅主题与字号三档、只读诊断与设置导出等主体已落地；部分高级口径
> （创作模式、sets 专用/通用优先级、备份恢复写入、LoRA 角色卡等）留后续切片。** 需求基线已确认；
> 运行形态为免安装本机浏览器 Web 应用（见 ADR-0002），不产出 EXE 安装包。

## 项目目标

在一个本机浏览器工作台中完成：

选择工作流 → 识别模型与提示词节点 → 按模型规则创作 Prompt → 用户审核 →
安全写入 → 卸载本地 LLM 并确认显存释放 → 提交 ComfyUI → 记录生成历史。

## 不可破坏的原则

1.  **工作流只允许修改用户确认的正向/负向 Prompt 白名单字段。**
    其他节点、参数、连接、Seed、尺寸、CFG、Steps、LoRA
    权重等必须保持不变。
2.  Prompt 先进入候选与审核流程；用户确认后才写入工作副本/任务数据。
3.  写入前后都做结构化差异检查；任何非白名单变化都拒绝提交。
4.  出图前必须完成本地 LLM 卸载与显存释放验证；无法确认时禁止提交。
5.  默认本地优先：不自动上传
    Prompt、草稿、图片或模型资料；第一版不接云端 AI API。
6.  草稿只在用户主动点击保存时持久化；生成历史自动记录。
7.  ComfyUI 由用户自行启动和关闭；工作台只连接和管理任务，不擅自控制
    ComfyUI 进程。
8.  原始工作流文件默认不覆盖；使用独立工作副本。

## 技术方向

-   免安装本机浏览器 Web 应用：FastAPI 同源托管前端产物与 API，访问 `http://127.0.0.1:17890`。
-   前端 React + TypeScript + Vite；后端 Python + FastAPI；本地数据 SQLite + `userdata/` 文件。
-   本地 LLM 第一版通过 Ollama 适配器接入。
-   ComfyUI 通过 HTTP + WebSocket 连接。
-   采用模块化单体，不拆微服务。

**注意：**
Tauri/Rust/PyInstaller/NSIS 路线已废弃（ADR-0001，历史记录见 `legacy/src-tauri/`）；
正式运行只需项目 `.venv` 的 Python 依赖，Node/Vite 仅用于构建前端产物。

## 本机使用

### 运行前提

- 项目自带独立 `.venv` Python 环境，正式运行只使用其中依赖；**不要**复用 ComfyUI
  整合包内部的 Python。Node/Vite 仅在重新构建前端产物时使用，正式运行不启动 Node 开发服务器。
- ComfyUI 与 Ollama 由用户自行启动和关闭；工作台只通过 HTTP 连接并管理任务，不擅自
  启停这两个外部进程。
- 前端产物位于 `frontend/dist/`，由构建生成，不入库；改动前端后需重新 `vite build`。

### 启动与停止

- 启动：双击 `启动工作台.bat`（等价于 `python scripts/workbench_launcher.py`）。
  服务在后台运行，健康检查通过后自动在默认浏览器打开 `http://127.0.0.1:17890`。
- 停止：双击 `停止工作台.bat`（等价于 `python scripts/workbench_stopper.py`）。
  停止器按 PID + 进程身份记录回收工作台进程树，不按名称批量结束 Python，也不触碰
  Ollama / ComfyUI。
- 可选环境变量：`WORKBENCH_HOST`（仅允许回环地址）、`WORKBENCH_PORT`（默认 17890）、
  `WORKBENCH_OPEN_BROWSER=0`（启动后不自动开浏览器）。

### 数据位置

所有本地数据落在仓库内 `userdata/`：SQLite 数据库、工作流副本与版本快照、档案、
导出文件、日志与备份。模型权重、原始图片不复制进工作台；`userdata/`、`dist/`、
`.venv/` 不入库。

### 安全边界

- 仅绑定 `127.0.0.1`，不开放局域网或公网；进程内会话票据 + CSRF 头 + Origin 白名单。
- 工作流只允许写入用户确认的正/负 Prompt 白名单字段；候选审核通过前不写入工作流。
- 不接云端 AI API，不自动上传 Prompt、草稿、图片或模型资料。
