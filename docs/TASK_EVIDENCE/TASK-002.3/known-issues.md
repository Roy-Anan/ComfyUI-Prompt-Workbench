# 已知问题与风险 — TASK-002.3

- 日期：2026-11-17

## 1. 本次已解决

- 启动器健康检查把 401 误判为未就绪：改为只要收到任意 HTTP 响应即视为服务已起（无令牌探测 health 返回 401 仍证明服务已起）。
- 启动器脱离运行后清理 PID 文件导致停止脚本找不到后端：改为分离进程（DETACHED_PROCESS / CREATE_NEW_PROCESS_GROUP）并持久保留后端 PID。
- 停止器依赖本机不可用的 `wmic`：改用 CIM（`Get-CimInstance Win32_Process`）查询子进程；仅终止记录 PID 及其子进程，不按名称批量结束 Python。
- `urllib.request.Request` 与 FastAPI `Request` 命名冲突导致探测异常：urllib 起别名 `UrlRequest`。
- Bearer 引导令牌做 POST 缺 CSRF 头被 403：Bearer 会话豁免 CSRF，仅 Cookie 会话校验。
