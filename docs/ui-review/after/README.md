# UI 改造后截图（after）

本目录存放《ComfyUI Prompt Workbench — UI 全面美化与体验升级计划书》落地后的**真实运行界面**截图，与上一级 `../screenshots/` 改造前基线一一对照。所有截图均来自本机真实运行的前端页面，不是设计稿、模拟图或代码截图。

## 截图环境

- 操作系统：Windows 11（i7-12650H，16GB 内存，RTX 4060 Laptop 8GB）。
- 浏览器：Google Chrome；桌面档为窗口最大化、视口 1920×1080；`14-narrow-workflow.png` 为还原后的较窄桌面窗口（约 1080px 宽），用于核对窄窗回落。
- 运行实例：本地 FastAPI 隔离实例，端口 `17894`，前端为 `frontend/dist` 最新构建产物；数据根沿用本机真实 `userdata/`（未另建测试数据根）。
- 主题 / 字号：浅色主题、标准字号。
- 操作口径：截图过程中只做只读查看、页面切换、选中工作流、打开弹窗；**未提交出图队列、未导入素材、未保存/删除草稿、未改动规则与设置**。两个导入弹窗均停留在空表单状态，点取消关闭，未点“开始导入”。
- 截图时本机真实数据状态：已登记工作流 3 个、规则 12 条、档案候选 13 份、LoRA 卡片 3 张；生成历史 0 条、素材 0 份、草稿 0 份、待发队列 0 条。
