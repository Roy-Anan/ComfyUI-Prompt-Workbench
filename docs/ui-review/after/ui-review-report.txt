三、各页面主要改进
------------------------------------------------------------
1. 工作流工作区（重点页）
   - 全局内容密度收敛：内容区间距、面板内边距、标题行距统一。
   - 顶部四张摘要信息卡（当前工作流 / 模型信息 / 采样参数 / 规则比对）紧凑分层，
     键值行间距收紧，主次信息不抢焦点。
   - 主双栏间距与节点行、列表行间距收紧。
   - 正 / 负向 Prompt 改为并排双栏（.prompt-pair，repeat(auto-fit, minmax(280px,1fr))）：
     单子项占满整行，双子项各占一栏；textarea 最小高度 150px。
   - 规则比对、本地候选等辅助区文字降权为辅助色，不与主编辑区争焦点。
   - 修复既有问题：主导航侧栏改为 sticky 固定（top:0; height:100vh），
     长页面向下滚动时主导航不再滚出视野（真机滚动两屏后复核固定可见）。

2. 服务与设置
   - 三张状态卡（工作台本地服务 / Ollama / ComfyUI）去掉多余最小高度，行距对齐。
   - 存储路径行、检查按钮对齐；长路径补 min-width:0，截断时不撑破布局。
   - 规则库卡片分层：标题、眉标（可信度·模型）、值、备注、右侧状态徽章与历史版本/删除入口。
   - 旧档案候选列表：架构 / 候选数 / 未识别数标注，档案目录路径与“打开档案目录”按钮。

3. LoRA 资料
   - 卡片内边距与间距收紧；缺资料/无资料标注、大小与校验状态分层；
     LoRA 来源长文本补 min-width:0，不撑破布局。

4. 生成历史
   - 时间轴、分组、筛选条间距紧凑；空态与列表/网格/时间轴/并排对比视图切换清晰。

5. 素材库
   - 左侧分组栏固定 184px，右侧自适应。
   - 网格 repeat(auto-fill, minmax(180px,1fr))，按可用空间自动调整列数。
   - 卡片 hover 品牌色边框，meta 区内边距统一；长文件名/路径截断保护。
   - 空态、离线提示行高 1.6。

6. 全局细节与响应式
   - 弹窗卡片补白色面板背景、统一阴影与圆角；遮罩中性柔和灰。
   - 响应式断点：
     · 1100px：Prompt 并排回落单栏；摘要 2 列；设置单列；设置二级导航横排。
     · 900px：应用单列；侧栏横排；摘要/网格单列；顶栏换行。
     · 760px：工作流双栏、候选对比回落单列。
   - 素材网格 auto-fill 与弹窗宽度在窄屏自适应（92vw/94vw）。
