ComfyUI Prompt Master V1.0
==========================

用途
----
这是给 Ollama 本地 LLM（如 Qwen3 / Qwen3-VL）使用的可扩展提示词规则包。
结构采用：
1. 核心系统提示词：规定通用行为和输出格式。
2. 模型数据库：把 checkpoint 文件名映射到专属配置。
3. 模型配置：记录架构、提示词习惯、作者参数、实测反馈。
4. 新模型模板：以后添加底模时复制并填写，不需要重写核心规则。

重要说明
--------
- 目前模型的架构分类是初始登记，部分文件名称不足以完全证明训练底座。
  遇到不确定项，请查看模型作者页面或 metadata 后再修正。
- 不要把“模型支持 NSFW”或社区标签理解为任何具体内容都能稳定生成。
- 采样器、步数、CFG、Clip Skip 等参数必须以对应版本作者说明或实测为准。
  本包不会为缺少依据的模型编造参数。
- SDXL、SD1.5、Pony、Illustrious 不是完全相同的提示词体系。
  模型配置优先于通用架构经验。
- 生成成人主题时，人物必须明确为成年人；不得把年龄模糊或年轻化描述当作成人设定。
- 先生成提示词，再由用户检查，之后复制到 ComfyUI。不要自动假设用户节点图与参数。

如何在 Ollama 中使用
--------------------
方法 A：作为 system prompt
1. 打开 系统提示词_全量版.txt。
2. 将全文放入 Ollama 对话的系统提示词 / 自定义指令位置。
3. 将 模型数据库.txt 与当前模型对应的 MODEL_PROFILES 文件内容一并提供给本地 LLM。
4. 告诉它当前 checkpoint 的完整文件名和你的画面创意。

方法 B：每次对话粘贴
1. 粘贴 系统提示词_全量版.txt。
2. 粘贴 模型数据库.txt。
3. 粘贴当前模型的配置文件（只贴当前那一个，不要全量塞入）。
4. 输入画面创意。

方法 C：Modelfile 持久化（可选）
1. 复制 系统提示词_全量版.txt 全文写入自定义 Modelfile 的 SYSTEM 指令。
2. 设 PARAMETER num_ctx 8192、temperature 0.7。
3. 执行 ollama create <模型名> -f Modelfile；数据库与单个 profile 仍按轮次粘贴。

新增模型
--------
1. 复制 TEMPLATES/NEW_MODEL_PROFILE_TEMPLATE.txt。
2. 按作者模型卡填写架构、提示词范例、参数和限制。
3. 将文件另存为 MODEL_PROFILES/你的模型名.txt。
4. 在 模型数据库.txt 增加一行映射。
5. 如果不确定参数，写“待核实”，不要猜。
6. 生成几张测试图，把结果写入 TEST_FEEDBACK/你的模型名_feedback.txt。

更新版本
--------
模型升级（例如 V2 -> V3）时，建议创建新配置文件，不要覆盖旧版本。
在数据库中分别登记，以便保留版本差异和实测记录。
