# ComfyUI Prompt Workbench V2.0 — 更新说明

发布日期：2026-11-15
上一版：阶段 6（显存自动管理）

## 一句话

V2.0 把前六个阶段的能力收进一个可日常使用的深色工作台：能看见运行状态、出错知道原因、图能点开看大图、设置能改、日志能查、数据能备份，最后打成 `ComfyUI_Prompt_Workbench_V2.0.zip`。

## 新增功能

### 1. 深色 UI

- 顶部品牌栏 + 状态 chip（Ollama / 模型 / ComfyUI / 显存）；
- 深色会话列表、工作流卡、聊天区、出图记录、弹层；
- 弹层统一玻璃感背景、圆角、阴影；移动端窄屏可用。

### 2. 运行状态

- 顶部运行条：运行时长、当前任务（对话 / 出图）、对话次数、出图次数、最近事件；
- 每 3 秒轮询 `/api/runtime`，页面隐藏时暂停；
- 对话 / 出图 / 失败 / 显存阶段都会更新运行条；
- 运行状态含最近一次显存步骤摘要和最近错误。

### 3. 图片预览

- 出图记录缩略图改为可点击按钮；
- 大图弹层：缩放（100%–400%）、适应窗口、下载原图、关闭；
- 底部显示文件名、大小、seed、步数、CFG、采样器、调度器、尺寸、耗时、正向摘要；
- Escape / 点遮罩关闭。

### 4. 错误提示

- 顶部红色错误条：标题、原因、`查看日志`、关闭；
- 右下 toast：成功 / 警告 / 错误，几秒自动消失；
- 对话失败、出图失败、重试失败、服务端 4xx/5xx 都会显示；
- 前端异常上报 `/api/client-log`，可在日志里查到。

### 5. 设置页面

五个 tab：

- **应用**：自动保存对话、出图后自动恢复 Ollama、删除前确认、深色主题；
- **对话**：历史消息条数 2–60、系统提示词版本（精简版 / 全量版）；
- **系统信息**：版本、Ollama / ComfyUI 地址与状态、数据目录、显存配置、历史统计、备份、日志、规则包体检；
- **备份**：备注、立即备份、备份列表、下载、删除；
- **关于**：版本、能力边界、数据与隐私说明。

保存走白名单，非法值会被忽略并给出黄色 warning；保存前自动备份旧设置。

### 6. 日志

- 文件 `logs\workbench.log`，JSON 行，UTF-8；
- 2 MB 滚动，保留 `workbench.log.1/.2/.3`；
- 页面右侧日志抽屉：路径、级别筛选、刷新、下载、条数；
- 记录对话 / 出图 / 显存 / 备份 / 设置 / 前端错误，不记提示词与对话正文；
- 重启后自动读回文件末尾，不会只剩“工作台启动”。

### 7. 备份

- 一键备份 `history\`、`settings\`、`workflows\`、`config.json`；
- ZIP 内 `manifest.json` 带每个文件的 SHA-256，列表做 CRC 校验；
- 备份名 `backup-YYYYMMDD-HHMMSS.zip`；
- 删除只移到 `backups\_trash\`，可手动找回；
- 备份不含 `outputs\` 出图原图与 `logs\`。

### 8. 说明与部署

- `README_使用说明.md` 改为 V2.0；
- 新增 `部署步骤_Windows.md`；
- 新增 `阶段7_实施记录.md`；
- 新增本文件 `更新说明.md`。

### 9. 最终 ZIP

- `dist\ComfyUI_Prompt_Workbench_V2.0.zip`；
- 排除 `history / settings / outputs / backups / dist / __pycache__ / chrome_headless`；
- `tools\verify_zip.py V2.0` 校验关键文件、CRC、中文名、无嵌套 ZIP、无用户数据。

### 10. 交接与多智能体协作

- 新增 `交接说明.md`：人类接手入口、当前状态、五分钟启动、验收清单；
- 新增 `AGENTS.md`：AI 智能体必读顺序、事实源优先级、目录归属、不可破坏约束、变更协议；
- 新增 `PROJECT_MANIFEST.json`：机器可读的版本、路径、命令、模块、阶段、数据边界；
- 新增 `tools\check_handover.py`：校验 manifest、文档、模块、测试、阶段证据和发布 ZIP 是否一致。

### 11. 启动自动打开浏览器

- `启动工作台.bat` 现在会传 `--open-browser`，服务绑定成功后自动打开默认浏览器；
- 直接运行 `app\server.py` 不会弹浏览器，方便冒烟测试和后台启动；
- 需要强制关闭时加 `--no-browser`。

### 12. 工作流内部索引不再出现在下拉

- `workflows\workflows_index.json` 是工作台导入记录，不是 ComfyUI 工作流；
- 之前它被 `list_all()` 误列为 `workflows_index.json · 导入 · 解析失败`；
- 现在列表、解析、删除都不再处理这个内部文件，ComfyUI 和工作台工作流照常显示。

## 行为变化（升级时注意）

| 变化 | 说明 |
| --- | --- |
| 版本号 | `2.0`；页面 `V2.0 · 正式版` |
| 图片点击 | 旧版是 `<a target="_blank">` 新窗口，现在改为页面内大图预览 |
| 设置保存 | 非法值不再整体拒绝，而是忽略该项并在 `warnings` 里说明 |
| 删除确认 | `confirm_delete` 现在是页面二次确认；直接调 API 不弹确认 |
| 日志 | 新增 `logs\workbench.log`，会持续写；2 MB 滚动 |
| 备份 | 新增 `backups\`；删除进 `_trash` |
| 错误计数 | 出图 400 校验失败也计入 `errors`，运行条会显示“出过错” |
| favicon | `/favicon.ico` 返回 204，浏览器不再报 404 |
| 出图恢复 | 设置里关掉“自动恢复 Ollama”会即时写入显存配置，下一次出图不再预加载 |
| 工作流列表 | `workflows_index.json` 内部索引不再出现在下拉，避免“解析失败”干扰 |

## 升级步骤

1. 停工作台；
2. 页面“设置 → 备份”立即备份；
3. 解压新 ZIP 到临时目录；
4. 覆盖 `app\ web\ rules\ profiles\ tests\ tools\` 与文档、`启动工作台.bat`；
5. **不要覆盖** `history\ settings\ outputs\ workflows\ backups\ logs\`；
6. 如改过端口 / 地址，把 `config.json` 对应值改回；
7. 启动，确认会话、出图记录、设置、工作流都在；
8. 跑一次 `tools\check_ui.py`，结论“通过”。

## 已知边界

- 只提供深色主题，浅色会被强制回 dark；
- 备份不含出图原图 `outputs\` 与日志 `logs\`；
- 页面日志只显示最近 600 条，更早的看文件；
- `tools\ui_probe.py` 需要 `websocket-client`，只是开发机自检工具；
- 端到端只在 RTX 4060 Laptop 8GB + ComfyUI 0.30.2 + Ollama 0.40.15 上实测；
- 8GB 显存下 Ollama 与 ComfyUI 仍只能串行，这是硬件边界，不是 V2.0 能消除的。
